EasyRead 安装说明
EasyRead Installation Guide

1. 双击“EasyRead.app”或将它拖入“应用程序”文件夹。
   Double-click “EasyRead.app”, or drag it to the “应用程序” (Applications) folder.

2. 第一次打开时，如果 macOS 提示无法验证开发者，请打开“系统设置 → 隐私与安全性”，点“仍要打开”（较新系统）；较旧系统也可在 Finder 中右键点击 App，选择“打开”并确认。
   If macOS says the developer cannot be verified, open System Settings → Privacy & Security
   and click “Open Anyway” (newer macOS), or right-click the app in Finder, choose
   “打开” (Open), and confirm (older macOS).

3. EasyRead 支持 TXT、Markdown、EPUB、PDF、MOBI、AZW、AZW3、FB2、CBZ、RTF、DOCX，全部格式都内置解码，无需安装 Calibre 或其他软件。
   EasyRead supports TXT, Markdown, EPUB, PDF, MOBI, AZW, AZW3, FB2, CBZ, RTF, and DOCX. Every format is decoded inside the app; no Calibre or other software is required.

4. 本安装包适用于文件名标注的架构（Intel / Apple Silicon / Universal），要求 macOS 12 或更高版本。
   This package targets the architecture in its file name (Intel / Apple Silicon / Universal) and requires macOS 12 or later.

5. 项目源码、开发者构建方法和问题反馈：
   Source code, developer build instructions, and issue reporting:
   https://github.com/KBDZequalsCK/EasyRead
