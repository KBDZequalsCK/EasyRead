# EasyRead 0.9.4

Release date: 2026-11-16

Platform: Intel (x86_64) Mac · macOS 12.0 or later

Build: 0.9.4 (43)

---

## English

This is the first public release since 0.3.1. It bundles every change from 0.4.0 through 0.9.4.

### What's new

**Every supported format is built in**

- Markdown (`.md` / `.markdown`) opens as formatted pages: headings, nested lists, task lists, quotes, code blocks, tables, links, strikethrough, and local images.
- MOBI, AZW, and AZW3 open without Calibre. The built-in decoder handles PalmDOC and HUFF/CDIC compression, KF8 skeleton and fragment tables, FDST flows, and resource images. DRM-protected Kindle books are still refused with a clear message.
- EPUB is parsed fully in-process through the system zlib; no `unzip` subprocess is started. Merged chapters rewrite relative resource paths, so illustrations display correctly.
- FB2 and CBZ are built-in formats.
- RTF and DOCX are built in, including headings, emphasis, Chinese code pages, WordprocessingML relationships, and `word/media` images.
- EPUB has an optional publisher-layout switch (View → 使用出版方排版) that inlines the book's CSS with rewritten resource URLs.

**Reading**

- A real table of contents for TXT, Markdown, EPUB, MOBI/AZW/AZW3, PDF, FB2, CBZ, RTF, and DOCX. Selecting a row jumps straight to that position.
- In-book search with ⌘F: WebKit find for HTML books, PDFKit highlighted matches for PDFs.
- Bookmarks and notes in one `bookmarks.json` store: ⌘D adds a bookmark, ⌘⇧N adds a note with optional selected text, ⌘⇧B opens the panel. Notes can be edited later, and a plain bookmark can be turned into a note.
- The last opened book is restored on launch, with its reading position.
- Comics have a native two-page spread mode: portrait pages are paired, landscape pages are shown alone, and arrow keys, PageUp/PageDown, space, the mouse wheel, and click zones all work. Page ranges such as `1–2 / 5` appear in the indicator, and bookmarks store the exact page.
- 0.9.4 fixes paged PDF progress and EPUB layout switching: PDF progress is throttled by page instead of one percent, bookmarks read `PDFView.currentPage`, and TOC/bookmark jumps refresh the indicator immediately. Toggling publisher layout now captures the live pager position first, so a 612-page book stays at the same passage instead of returning to page 1.
- 0.9.4 also removes the pause when showing or hiding the bookshelf. The frozen column grid and page count stay unchanged while only the visible frame moves, so the transition no longer reflows the book or leaks half of the previous page.

**Libraries and sync**

- Three peer libraries, one active at a time: iCloud, Jianguoyun, or a local Mac folder. Each has its own bookshelf and remembered folder.
- Jianguoyun is a full cloud library, not just a progress channel. Upload pushes Mac books and this Mac's reading positions; download pulls cloud books and their positions. Each action writes a new timestamped snapshot and never overwrites older ones.
- Right-click a Jianguoyun book and choose 从坚果云删除并移出书架 to write a deletion snapshot (`isRemove` plus a file tombstone) and remove this Mac's shelf record and cache copy. Older snapshots remain intact.
- Snapshots use the real ZenReader v1 layout, including `objects/books/<SHA-256>.<ext>`, `extraJSON.webdav.path`, and per-snapshot plus root manifests. Snapshot digests follow ZenReader's canonical payload, so snapshots uploaded by the Mac are accepted by the phone again.
- The saved Jianguoyun app password lives only in the login keychain. It is read silently; launch, status checks, and automatic sync never show the macOS authorization dialog. EasyRead is intentionally built unsigned so its keychain partition stays stable across rebuilds.
- Sync state is visible: a spinner plus phase text such as “Downloading 2/5…” or “Writing cloud snapshot…”, disabled buttons while a sync runs, and a “Last sync” timestamp when idle.
- Transfers run up to three books in parallel and stream between disk and network. A dropped keep-alive connection is retried once.

**Performance**

- Rendered pages are cached per book, so later opens start in about a second.
- Extracted chapter models are cached on disk for up to 24 books, avoiding repeated parsing on launch and sync.
- TXT books are split into ordinary paragraphs, cutting WebKit's multi-column layout for a 1 MB novel from about 11.8 s to about 0.75 s.
- Images use lazy loading in every web format. CBZ pages are read on demand from the archive instead of being extracted to disk.
- Reading progress is coalesced into at most one `library.json` write per 0.8 s and flushed on quit or when the app loses focus.

### Upgrade notes

- Drag EasyRead.app from the DMG into the Applications folder. The bundle identifier is unchanged, so the bookshelf, reading preferences, and window layout are preserved.
- After upgrading from 0.4.15 or earlier, enter the Jianguoyun app password once in settings. The current build stores it in the `EasyRead.ZenReaderWebDAV.v4` keychain item and reads it silently afterwards.
- The rendered-page cache version was bumped several times; the first open of each book rebuilds its cache.
- Markdown, FB2, CBZ, RTF, and DOCX are Mac-local formats. Jianguoyun upload skips `.md`, `.markdown`, `.fb2`, `.cbz`, `.rtf`, and `.docx` files, so they stay in the local bookshelf and are not written to cloud snapshots.

### Download and installation

1. Download `EasyRead-Intel-0.9.4.dmg`.
2. Open the DMG and drag EasyRead.app into the Applications folder.
3. If macOS blocks the first launch, right-click the app in Finder and choose Open.
4. The DMG includes a bilingual 使用说明.txt with the same steps.

### Verification

- Binary architecture: Intel x86_64.
- Version: 0.9.4 (build 43); the About panel shows `Version 0.9.4 (43)`.
- Real-app checks covered every supported format, the table of contents, search, bookmarks and notes, comic spreads, publisher layout, and PDF page-accurate progress.
- The sidebar transition was recorded at 60 fps: one transition frame, no leaked previous-page frames, and the page number stays unchanged (`1 / 260 → 6 / 260 → 6 / 260` across show, page turns, hide, and show again).

### Known limitations

- This build is for Intel Macs only and requires macOS 12 or later.
- DRM-protected Kindle books cannot be decoded.
- ZenReader has no renderer for Markdown, FB2, CBZ, RTF, or DOCX, so those books are not uploaded to Jianguoyun.
- Reading positions for MOBI, AZW, and AZW3 may be approximate on the phone because chapter boundaries can differ from the built-in decoder.

## 中文

这是 0.3.1 之后的首个公开版本，包含 0.4.0 至 0.9.4 的全部改动。

### 主要更新

**全部格式内置解码**

- Markdown（`.md` / `.markdown`）按排版页面打开，支持标题、嵌套列表、任务列表、引用、代码块、表格、链接、删除线和相对路径本地图片。
- MOBI、AZW、AZW3 不再依赖 Calibre，内置解析器直接读取 PalmDOC、HUFF/CDIC、KF8 骨架/片段表、FDST 文本流和图片资源；带 DRM 的书仍会明确提示无法解码。
- EPUB 完全进程内解析，使用 macOS 自带 zlib，不再启动 `unzip`；合并章节会重写相对资源路径，插图可以正常显示。
- 新增内置 FB2 与 CBZ 格式。
- 内置 RTF 与 DOCX：解析标题、强调、中文字符集、WordprocessingML 关系表和 `word/media` 图片。
- EPUB 可在“显示 → 使用出版方排版”中启用出版方 CSS，资源路径会自动重写。

**阅读体验**

- TXT、Markdown、EPUB、MOBI/AZW/AZW3、PDF、FB2、CBZ、RTF、DOCX 都有真正的目录，点击条目即可跳转。
- ⌘F 全书搜索：网页格式使用 `WKWebView.find`，PDF 使用 `PDFDocument.findString` 并高亮匹配。
- 书签与笔记共用 `bookmarks.json`：⌘D 加书签，⌘⇧N 加笔记（可附带选中文字），⌘⇧B 打开面板；笔记可再次编辑，普通书签也能补写笔记。
- 启动时恢复上次打开的书及阅读位置。
- 漫画支持原生双页：竖页左右并排，横页单独显示；方向键、PageUp/PageDown、空格、滚轮和左右半屏点击均可翻页；页码显示 `1–2 / 5`，书签保存精确页码。
- 0.9.4 修复分页 PDF 进度与 EPUB 排版切换：PDF 按页记录进度，书签直接读当前可见页，目录/书签跳转后页码立即刷新；开关出版方排版前先捕获当前阅读位置，612 页的大书不会回到第 1 页。
- 0.9.4 同时修复书架显示/隐藏时的卡顿与“一页半”残影：冻结分栏网格和总页数不变，只移动可见窗口，切换不再整书重排，也不会露出上一页的半页内容。

**书库与同步**

- iCloud、坚果云、本地文件夹三个完全同级的书库，同一时间只使用一个；各自拥有独立书架并记住上次文件夹。
- 坚果云是完整云端书库：“上传”推送本机书籍和本机阅读进度，“下载”拉取云端书籍及其进度；每次操作新建带时间戳的快照，绝不覆盖旧快照。
- 右键坚果云书籍可“从坚果云删除并移出书架”，写入 `isRemove` 和文件墓碑，同时移除本机记录与下载缓存，旧快照仍可找回。
- 快照按真实 ZenReader v1 布局写入，包含 `objects/books/<SHA-256>.<扩展名>`、`extraJSON.webdav.path`、快照 manifest 和根 manifest；摘要改用手机端认可的规范化载荷，Mac 上传的快照可以再次通过手机校验。
- 坚果云应用密码只保存在 macOS 登录钥匙串，启动、状态检查和自动同步都静默读取，不再弹出授权框；App 有意保持未签名，使钥匙串分区在重建后保持稳定。
- 同步过程显示实时状态：旋转指示器和“正在下载 2/5…”“正在写入云端快照…”等阶段文字；同步期间按钮禁用，空闲时显示最近同步时间。
- 传输最多三本书并行，文件以流的方式在磁盘和网络之间传输；keep-alive 连接静默断开时会重试一次。

**性能**

- 每本书的渲染页都有缓存，再次打开约一秒启动。
- 章节模型在磁盘缓存最多 24 本书，启动和同步不再重复解析。
- TXT 按自然段拆分，1 MB 小说的 WebKit 分栏从约 11.8 秒降到约 0.75 秒。
- 所有网页格式的图片懒加载；CBZ 漫画按需从压缩包读取页面，不再整本解压到磁盘。
- 阅读进度最多每 0.8 秒合并写入一次 `library.json`，退出或失焦时强制落盘。
