## 中文

### 本次更新

- **应用正式更名为 EasyRead**：访达中的 App 名称、菜单栏应用菜单、窗口标题、“关于”面板和 DMG 卷标统一使用英文名。
- **解决 0.3.0 的菜单名限制**：macOS 会强制菜单栏最左侧显示应用包名，现在包名已改为 EasyRead，中英文界面下都显示 EasyRead。
- **中文界面继续保留**：应用默认仍为中文，可从应用菜单「语言 / Language」或书架右下角切换中英文，选择会被记住。
- 重新构建 Intel x86_64 版本并更新 DMG 安装包。

### 升级说明

- 将 DMG 中的 EasyRead.app 拖入“应用程序”文件夹即可。新版本沿用原有 Bundle ID，书架数据、阅读偏好和窗口布局都会保留。
- 如果“应用程序”文件夹里还留有旧的“简阅.app”，确认新版本运行正常后可手动删除。

### 下载与安装

1. 下载 `EasyRead-Intel-0.3.1.dmg`。
2. 打开 DMG，将 EasyRead.app 拖入“应用程序”文件夹。
3. 首次启动若被 macOS 阻止，请在 Finder 中右键点击 App，选择“打开”。
4. DMG 内的“使用说明.txt”包含中英双语安装提示。

- 版本信息：0.3.1（build 7），关于面板显示 `Version 0.3.1 (7)`。
- 已验证中文与英文界面下菜单栏应用名均为 EasyRead，语言切换和窗口标题正常。
- DMG 已挂载检查，内含 EasyRead.app（x86_64、0.3.1）。
- DMG SHA256：`3ea7ea64c7fa1ee1300d45427088ed72485d702fc45955c62855ae116641f2e6`

## English

### What's new

- **Renamed the app to EasyRead**: the Finder app name, menu bar application menu, window titles, About panel, and DMG volume now use the English name consistently.
- **Fixes the 0.3.0 menu-title limitation**: macOS forces the leftmost menu title to the bundle name. The bundle name is now EasyRead, so it appears as EasyRead in both Chinese and English modes.
- **Chinese UI remains available**: the app still starts in Chinese by default, and you can switch between Chinese and English from the app menu (**Language / 语言**) or the library footer. The choice is remembered.
- Rebuilt the Intel x86_64 app and refreshed the DMG package.

### Upgrade notes

- Drag EasyRead.app from the DMG into the Applications folder. The app keeps the same bundle identifier, so the bookshelf, reading preferences, and window layout are preserved.
- If the old 简阅.app is still in Applications, you can remove it manually after confirming the new version works.

### Download and installation

1. Download `EasyRead-Intel-0.3.1.dmg`.
2. Open the DMG and drag EasyRead.app into the Applications folder.
3. If macOS blocks the first launch, right-click the app in Finder and choose Open.
4. The DMG includes a bilingual 使用说明.txt with the same steps.
