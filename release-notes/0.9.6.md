Platform: Intel (x86_64) Mac · macOS 12.0 or later

## English

### What's new

**EasyRead Pro is now on sale**

- The Pro purchase button is active. It opens the live 爱发电 product: <https://ifdian.net/item/433d9ac0e31111f181f552540025c377>.
- The product costs ¥8 as a one-time purchase and allows repeat purchases. 爱发电's automatic reply issues one code per order, so buy one order per Mac.
- Activation still needs no account, order lookup, or license server. The Ed25519 signature is checked offline on this Mac.

**A code binds to its first Mac**

- On the first successful activation, the code binds to the current Mac. EasyRead stores only a SHA-256 hash of the host UUID, never the raw UUID, and checks the hash on later launches.
- A license saved by 0.9.5 has no binding yet; 0.9.6 binds it silently on the first launch, so existing users do not need to activate again.
- If the saved binding belongs to another Mac, EasyRead removes the local license and the Pro window asks for the code again. Re-entering the code, or contacting the developer, handles a legitimate move to a new Mac.
- This is a local anti-copying measure, not a server-enforced one-device lock. Someone who has the raw code can still activate it on another Mac; do not describe it as DRM.

**Everything from 0.9.5 remains**

- The folder library, imports, reading, bookmarks, and notes are free. Pro unlocks the WebDAV library, sync settings, upload/download, and automatic sync.
- The merged folder library, configurable WebDAV provider and cloud folder, and the 0.9.5 reading fixes are unchanged.

### Purchase and activation

1. In EasyRead, choose **Library → Unlock EasyRead Pro (¥8)…** and click **Buy a license**.
2. Pay on the 爱发电 product page. The code is sent automatically to the order or site message.
3. Paste the code into the Pro window and click **Activate**.
4. If the code does not arrive, contact the developer through 爱发电's site message with the order number.

爱发电 charges 6% in total (5% platform + 1% payment channel), so the creator receives about 94%.

### Download and installation

1. Download `EasyRead-Intel-0.9.6.dmg`.
2. Open the DMG and drag EasyRead.app into the Applications folder.
3. If macOS blocks the first launch, right-click the app in Finder and choose Open.
4. The DMG includes a bilingual 使用说明.txt with the same steps.

### Verification

- Binary architecture: Intel x86_64; version 0.9.6 (build 45); intentionally unsigned.
- The Pro purchase button was checked end to end with an empty license: it opened exactly the product URL above.
- Device binding was checked on this Mac: the developer license bound automatically on first launch; changing the stored binding to a different hash made the app remove the license and show the “bound to another Mac” message; restoring the data and activating again wrote the binding and survived a relaunch.
- The DMG was mounted and checked; it contains EasyRead.app (x86_64, 0.9.6), the Applications shortcut, and the installation guide.
- DMG SHA256: `a130157f9a424f0b06727cbbf374f8610635fd279472c58c86a1f3ebbffa6b8f`

### Known limitations

- One real ¥8 order has not yet confirmed that 爱发电's automatic reply sends exactly one unique code per order. The setup is configured, but this order-level behavior is still pending a live test.
- Device binding is local only. It deters copying a saved license, but it cannot stop someone who has the raw code from activating it elsewhere.
- This build is for Intel Macs only and requires macOS 12 or later.
- DRM-protected Kindle books cannot be decoded.
- There is no server-side license or device registry; binding is local. Treat codes as software keys and do not share them.

## 中文

### 主要更新

**EasyRead Pro 已上架**

- Pro 购买按钮已启用，直接打开已上架的爱发电商品：<https://ifdian.net/item/433d9ac0e31111f181f552540025c377>。
- 商品为 ¥8 一次性买断，不限制购买数量。爱发电“自动随机回复”每笔订单发送一条授权码，多台 Mac 请分多次下单，每次购买 1 份。
- 激活仍然不需要账号、订单查询或授权服务器；Ed25519 签名在本机离线校验。

**授权码首次激活绑定当前 Mac**

- 首次激活成功时，授权码会绑定当前 Mac。EasyRead 只保存主机 UUID 的 SHA-256 单向哈希，不保存原始 UUID，并在之后每次启动时比对。
- 0.9.5 保存的授权码还没有绑定信息；0.9.6 首次启动会自动把它绑定到当前 Mac，老用户不需要重新激活。
- 如果本机保存的绑定属于另一台 Mac，EasyRead 会移除本机授权，Pro 窗口会提示重新输入。正常换机时重新输入授权码，或联系作者处理。
- 这是本地的防拷贝措施，不是服务器强制的“一码一机”。拿到原始授权码的人仍可在另一台 Mac 上激活；不要把它宣传成 DRM。

**0.9.5 的功能保持不变**

- 文件夹书库、导入、阅读、书签和笔记永久免费。Pro 解锁 WebDAV 书库、同步设置、上传 / 下载和自动同步。
- 合并后的文件夹书库、可配置的 WebDAV 服务商与云端目录，以及 0.9.5 的阅读修复均保持不变。

### 购买与激活

1. 在 EasyRead 中选择 **书库 → 解锁 EasyRead Pro（¥8）…**，点击 **购买授权**。
2. 在爱发电商品页付款，授权码会自动发送到订单或站内私信。
3. 把授权码粘贴到 Pro 窗口，点击 **激活**。
4. 如果没有收到授权码，请通过爱发电站内私信联系作者，并附上订单号。

爱发电总计抽 6%（平台 5% + 支付通道 1%），创作者到账约 94%。
