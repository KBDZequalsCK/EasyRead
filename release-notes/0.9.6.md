# EasyRead 0.9.6

Release date: 2026-11-26

Platform: macOS 12.0 or later · Intel and Apple silicon (this DMG is an x86_64 build; Apple silicon runs it via Rosetta 2)

Build: 0.9.6 (45)

---

## English

### What's new

**Every feature is free again**

- The WebDAV library no longer needs a Pro license or a purchase. The license checks, activation window, purchase link, and app-menu entry were removed.
- The WebDAV shelf, sync settings, upload/download, and automatic sync are available to everyone, just like the folder library.
- No account, license code, order lookup, or activation server is involved.
- Choosing the WebDAV library no longer falls back to the folder library when no license is stored.

**Includes the 0.9.5 library and sync improvements**

- The old iCloud library and local-folder library are now one **folder library**: one chosen folder, one shelf, with existing records migrated automatically.
- WebDAV remains a full peer library. The settings window offers a provider picker (Jianguoyun, Nextcloud, InfiniCLOUD, Synology, Custom WebDAV) and a cloud-folder choice: **EasyRead (Default)** for new setups, or **ZenReader (Compatible)** for sharing with ZenReader on iPhone/iPad.
- The server field accepts the account root only. EasyRead appends `EasyRead/` or `ZenReader/v1/` itself and creates the directories on the first sync.
- Switching the cloud folder affects later syncs only; the other folder is left untouched.
- Empty cloud accounts can complete their first sync and create an empty snapshot.

**Reading**

- The bookshelf starts empty; the last book is not reopened automatically on launch.
- The expanded table-of-contents group follows the current reading position.
- A−/A+ applies the font size immediately, with one debounced reflow after repeated clicks.
- TXT pagination, TOC jumps, PDF page progress, EPUB publisher-layout switching, and the bookshelf show/hide transition keep the fixes from 0.9.4.

**Compatibility**

- Bundle identifier, bookshelf file, bookmarks file, reading preferences, and window layout are unchanged.
- Existing WebDAV users without a cloud-folder preference stay on `ZenReader/v1`; new setups use `EasyRead/`.
- Existing WebDAV passwords in the macOS Keychain remain valid.
- A license previously stored in preferences is simply ignored; it is no longer required.

### Download and installation

1. Download `EasyRead-Intel-0.9.6.dmg`.
2. Open the DMG and drag EasyRead.app into the Applications folder.
3. If macOS blocks the first launch, right-click the app in Finder and choose Open.
4. The DMG includes a bilingual 使用说明.txt with the same steps.

### Verification

- Binary architecture: Intel x86_64; version 0.9.6 (build 45); intentionally unsigned.
- `./build.sh` completes without errors, and the built app starts as a normal AppKit application.
- A repository-wide search finds no license activation, purchase link, or Pro gating left in the source, Info.plist, or app menu.
- The DMG was mounted and checked: it contains EasyRead.app (x86_64, 0.9.6), the Applications shortcut, and the bilingual installation guide; the app's Info.plist has no purchase URL and the binary contains no Pro strings.
- DMG SHA256: `7696f17c35fde61e4e7e50c53f87f1c368e2385686deb4d701dc76d2d4fa047c`

### Known limitations

- This DMG is an x86_64 build and requires macOS 12 or later; on Apple silicon it runs through Rosetta 2. Build from source with `ARCH=arm64 ./build.sh` or `ARCH=universal ./build.sh` for a native Apple silicon app.
- DRM-protected Kindle books cannot be decoded.
- WebDAV passwords are stored only in the macOS Keychain; HTTPS is required except for localhost testing.

## 中文

### 主要更新

**全部功能恢复免费**

- WebDAV 书库不再需要 Pro 授权或购买，授权校验、激活窗口、购买链接和应用菜单入口全部移除。
- WebDAV 书架、同步设置、上传 / 下载和自动同步与文件夹书库一样，对所有人开放。
- 不需要账号、授权码、订单查询或激活服务器。
- 即使本机没有保存任何授权，选择 WebDAV 书库也不会再回退到文件夹书库。

**包含 0.9.5 的书库与同步改进**

- 旧的 iCloud 书库与本地书库合并为一个 **书库**：只选择一个文件夹、维护一份书架，旧记录会自动迁移。
- WebDAV 仍是完整的同级书库。设置窗口提供服务商选择（坚果云、Nextcloud、InfiniCLOUD、群晖、自定义 WebDAV）和云端目录选择：新用户默认 **EasyRead（默认）**，需要与 iPhone/iPad 上的极简阅读互通时选 **ZenReader（兼容）**。
- 服务器地址只填账号根目录，EasyRead 会自己追加 `EasyRead/` 或 `ZenReader/v1/`，并在首次同步时创建目录。
- 切换云端目录只影响之后的同步，另一个目录中的内容不会被移动或删除。
- 空账号首次同步会创建一份空快照。

**阅读**

- 启动时书架为空，不再自动打开上次的书。
- 目录展开的分组跟随当前阅读位置。
- A−/A+ 立即改变字号；连续点击只会在最后一次点击后做一次防抖重排。
- 保留 0.9.4 的 TXT 分页、目录跳转、PDF 按页进度、EPUB 出版方排版切换和书架显示/隐藏优化。

**兼容性**

- Bundle ID、书架文件、书签文件、阅读偏好和窗口布局均未改变。
- 没有云端目录偏好的旧 WebDAV 用户继续使用 `ZenReader/v1`；新配置默认使用 `EasyRead/`。
- macOS 钥匙串中已保存的 WebDAV 密码继续有效。
- 以前保存在偏好设置里的授权会被直接忽略，不再需要授权。
