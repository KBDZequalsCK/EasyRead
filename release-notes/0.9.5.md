## English

### What's new

**EasyRead Pro and the WebDAV library**

- The folder library (iCloud Drive or any local folder), imports, reading, bookmarks, and notes remain free.
- The WebDAV library is now a one-time **¥8 EasyRead Pro** unlock. Pro covers the WebDAV shelf, sync settings, upload/download, and automatic sync.
- License codes use an offline Ed25519 signature. Activation needs no account, order lookup, license server, or network connection; the code is verified on this Mac and stored locally.
- Unlock from **Library → Unlock EasyRead Pro (¥8)…** or by choosing the locked WebDAV shelf. After activation, WebDAV is not switched on automatically.
- A developer license is already active on the developer's Mac, outside the public repository.

**Libraries and sync**

- The old iCloud library and local-folder library are now one **folder library**: one chosen folder, one shelf, with existing records migrated automatically.
- WebDAV remains a full peer library. The settings window adds a provider picker (Jianguoyun, Nextcloud, InfiniCLOUD, Synology, Custom WebDAV) and a cloud-folder choice: **EasyRead (Default)** for new setups, or **ZenReader (Compatible)** for sharing with ZenReader on iPhone/iPad.
- The server field now accepts only the account root. EasyRead appends `EasyRead/` or `ZenReader/v1/` itself and creates the directories on the first sync.
- Switching the cloud folder affects later syncs only; the other folder is left untouched.
- Empty cloud accounts can now complete their first sync and create an empty snapshot instead of returning without doing anything.

**Reading**

- The bookshelf now starts empty; the last book is no longer opened automatically on launch.
- The expanded table-of-contents group follows the current reading position instead of an earlier group.
- A−/A+ applies the font size immediately, with one debounced reflow after repeated clicks.
- TXT pagination, TOC jumps, PDF page progress, EPUB publisher-layout switching, and the bookshelf show/hide transition keep the fixes from 0.9.4.

**Compatibility**

- Bundle identifier, bookshelf file, bookmarks file, reading preferences, and window layout are unchanged.
- Existing WebDAV users without a cloud-folder preference stay on `ZenReader/v1`; new setups use `EasyRead/`.
- Existing WebDAV passwords in the macOS Keychain remain valid.

### Download and installation

1. Download `EasyRead-Intel-0.9.5.dmg`.
2. Open the DMG and drag EasyRead.app into the Applications folder.
3. If macOS blocks the first launch, right-click the app in Finder and choose Open.
4. The DMG includes a bilingual 使用说明.txt with the same steps.

### Verification

- Binary architecture: Intel x86_64; version 0.9.5 (build 44).
- The final app was launched with real preferences; the free folder library opened and displayed books.
- License validation was checked with an invalid code and a valid code, across relaunch, with a corrupt stored code, and when removing Pro so a saved WebDAV shelf falls back to the folder shelf without overwriting the preference.
- The Pro window was checked in light mode, dark mode, and English.
- The DMG was mounted and checked; it contains EasyRead.app (x86_64, 0.9.5) and the Applications shortcut.
- DMG SHA256: `2efd0218608b88c5973327f83f74688789df52f76ca045960c2357e199eceebe`

### Known limitations

- This DMG is an x86_64 build and requires macOS 12 or later; on Apple silicon it runs through Rosetta 2.
- DRM-protected Kindle books cannot be decoded.
- License codes are not device-bound. Treat them as software keys and do not share them.

## 中文

### 主要更新

**EasyRead Pro 与 WebDAV 书库**

- “书库”（iCloud Drive 或任意本地文件夹）、导入、阅读、书签和笔记永久免费。
- WebDAV 书库改为 ¥8 的 **EasyRead Pro** 一次性解锁，包含 WebDAV 书架、同步设置、上传 / 下载和自动同步。
- 授权码使用 Ed25519 离线签名校验，激活不需要账号、订单查询、授权服务器或联网；授权码在本机校验并保存在本机。
- 可从 **书库 → 解锁 EasyRead Pro（¥8）…** 或点击带锁的 WebDAV 入口解锁。激活后不会自动切换到 WebDAV。
- 开发者的 Mac 已注入开发者授权，授权码保存在公开仓库之外。

**书库与同步**

- 旧的 iCloud 书库与本地书库合并为一个 **书库**：只选择一个文件夹、维护一份书架，旧记录会自动迁移。
- WebDAV 仍是完整的同级书库。设置窗口新增服务商选择（坚果云、Nextcloud、InfiniCLOUD、群晖、自定义 WebDAV）和云端目录选择：新用户默认 **EasyRead（默认）**，需要与 iPhone/iPad 上的极简阅读互通时选 **ZenReader（兼容）**。
- 服务器地址只填账号根目录，EasyRead 会自己追加 `EasyRead/` 或 `ZenReader/v1/`，并在首次同步时创建目录。
- 切换云端目录只影响之后的同步，另一个目录中的内容不会被移动或删除。
- 空账号首次同步会创建一份空快照，不再直接返回。

**阅读**

- 启动时书架为空，不再自动打开上次的书。
- 目录展开的分组跟随当前阅读位置，不会提前展开更早的分组。
- A−/A+ 立即改变字号；连续点击只会在最后一次点击后做一次防抖重排。
- 保留 0.9.4 的 TXT 分页、目录跳转、PDF 按页进度、EPUB 出版方排版切换和书架显示/隐藏优化。

**兼容性**

- Bundle ID、书架文件、书签文件、阅读偏好和窗口布局均未改变。
- 没有云端目录偏好的旧 WebDAV 用户继续使用 `ZenReader/v1`；新配置默认使用 `EasyRead/`。
- macOS 钥匙串中已保存的 WebDAV 密码继续有效。
