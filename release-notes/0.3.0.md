# 简阅 0.3.0 / EasyRead 0.3.0

发布日期 / Release date: 2026-11-13

平台 / Platform: Intel (x86_64) Mac · macOS 12.0 或更高版本 / or later

构建 / Build: 0.3.0 (6)

## 中文

### 本次亮点

界面支持中文 / English 实时切换：默认仍是中文，切换后无需重启，应用内所有主要界面会立即使用所选语言。

### 新增功能

- **两种切换入口**：可以从应用菜单「语言 / Language」中选择「中文」或「English」，也可以点击书架右下角的语言链接快速切换。
- **即时生效，无需重启**：书架标题与按钮、阅读器工具栏、空书架提示、右键菜单、对话框、菜单栏都会立即刷新。
- **记住选择**：语言偏好保存在本机，下次启动继续使用上次选择的语言；首次启动默认中文。
- **完整的英文界面**：包括应用菜单、编辑菜单、关于面板、导入 / 同步 / 位置按钮、iCloud 同步状态、书籍作者与阅读进度、错误提示和确认对话框。
- **英文排版适配**：侧栏按钮在英文下使用紧凑标签（Import / Sync / Folder）并配有悬停说明，避免文字截断；云同步状态在英文下正确显示单复数（1 book / N books）。
- **阅读中的书籍同步更新**：切换语言时，正在阅读的书籍副标题和加载提示也会随之更新。

### 改进

- 云同步状态改为结构化枚举渲染，切换语言后状态不会被重置或丢失。
- 本地化采用运行时字符串选择，而不是独立的语言资源包，因此切换更直接，也不会复制两套界面代码。
- 应用启动时会同步系统的 `AppleLanguages` 设置，让 AppKit 提供的标准界面元素跟随所选语言。
- 重新构建 Intel x86_64 版本，并更新 DMG 安装包。

### 已知限制

- macOS 会强制把应用菜单最左侧的标题显示为应用包名「简阅」，这一处无法在运行时修改；切换为英文后它仍是品牌名，其余菜单项均为英文。
- 本版本仍面向 Intel Mac；MOBI、AZW、AZW3 需要安装 Calibre 才能转换。

### 下载与安装

1. 下载 `EasyRead-Intel-0.3.0.dmg`。
2. 打开 DMG，将「简阅.app」拖入「应用程序」文件夹。
3. 首次启动若被 macOS 阻止，请在 Finder 中右键点击 App，选择「打开」。
4. DMG 内的「使用说明.txt」包含中英双语安装提示。

开发者可从仓库 main 分支按 README 的 `./build.sh` 和 `./package-dmg.sh` 自行构建。

## English

### Highlights

The interface now switches between Chinese and English at runtime. Chinese remains the default, and no restart is needed — every major surface updates immediately after switching.

### New features

- **Two ways to switch**: choose 中文 or English from the app menu (**Language / 语言**), or click the language link in the bottom-right corner of the library sidebar.
- **Instant updates, no restart**: the library header and buttons, reader toolbar, empty-state copy, context menus, dialogs, and menu bar all refresh immediately.
- **Remembered choice**: the language preference is stored locally and restored on the next launch. Chinese is used by default on first launch.
- **Complete English UI**: the app menu, Edit menu, About panel, Import / Sync / Folder buttons, iCloud sync status, book author and reading progress, error messages, and confirmation dialogs are all localized.
- **English layout tuning**: sidebar actions use compact labels (Import / Sync / Folder) with explanatory tooltips to avoid truncation, and iCloud status text handles singular and plural counts correctly (1 book / N books).
- **Live reader updates**: if a book is open while switching languages, its subtitle and loading messages update as well.

### Improvements

- iCloud sync status is now rendered from a structured enum, so the current status survives a language switch instead of being reset or lost.
- Localization uses runtime string selection rather than separate language bundles, which keeps switching immediate without duplicating UI code.
- The app synchronizes the system `AppleLanguages` setting at launch so standard AppKit interface elements follow the selected language.
- Rebuilt the Intel x86_64 app and refreshed the DMG package.

### Known limitation

- macOS forces the leftmost application menu title to the bundle name 简阅, and it cannot be changed at runtime. It remains the brand name in English mode; all other menu items are in English.
- This release is still for Intel Macs. MOBI, AZW, and AZW3 require Calibre for conversion.

### Download and installation

1. Download `EasyRead-Intel-0.3.0.dmg`.
2. Open the DMG and drag 简阅.app into the Applications folder.
3. If macOS blocks the first launch, right-click the app in Finder and choose Open.
4. The DMG includes a bilingual 使用说明.txt with the same installation steps.

Developers can build from the main branch with `./build.sh` and `./package-dmg.sh` as described in the README.

- The DMG was mounted and checked; it contains the 0.3.0 Intel app.
